# Zia Developer AI

**In development**

Tumhara AI build partner Claude Code aur OpenCode ke andar. Problem describe karo; yeh kitab se sahi architecture chunta hai, spec likhta hai, aur agent build karta hai.

Zia Developer AI tumhare coding agent ke liye ek plugin hai — Claude Code ya OpenCode. Plain language mein business problem describe karo aur yeh guess ki jagah ek **decision** deta hai: Mode 1 ya Mode 2, aur kaun si shape, kitab par grounded. Phir spec likhta hai aur us par working agent build karta hai. Tum verify karo aur ship karo.

[The FDE AF Model](/docs/ecosystem/fde-af-model) mein Zia Developer AI reference domain builder hai: Layer 2 slot jo har vertical apne architectures aur compliance rules se preloads karta hai, toh jo agents produce karein woh us profession ke constraints ko default par respect karein.

---

## Yeh kya karta hai

### Decide karta hai, phir banata hai

Kitab ke decision gates chalata hai sahi shape chunne ke liye, reason cite karta hai, spec likhta hai, aur working, deployable agent scaffold karta hai — disposable skeleton nahi.

### Gate par kabhi guess nahi karta

Jab tumhari requirements decision settle nahi karti, yeh ek sabse sharp sawaal poochta hai aur wait karta hai. Spec-driven discipline, architecture choice par apply.

### Tumhare paas pehle se jo agent hai usmein

Yeh ek command se marketplace se Claude Code ya OpenCode mein install hota hai. Decision knowledge portable skill hai, toh har host tak pahunchta hai — economy-tier models bhi.

### Usi well se grounded

Yeh wohi System of Record padhta hai jo Zia Tutor AI. Har recommendation kitab par grounded hai, aur yeh fail closed hota hai rather than woh architecture invent kare jise cite nahi kar sake.

---

## Yeh kya rhythm lagata hai

Yeh kitab ka 10-80-10 building par apply hai: Zia Developer AI intent set karta hai — architecture decision aur spec, pehle 10% — tumhara coding agent build execute karta hai, 80%, aur tumhara judgment loop close karta hai, aakhri 10%. Yeh Zia Tutor AI ka mirror hai: wohi source, doosra host. Jahan tutor method sikhata hai, developer use chalaata hai.
