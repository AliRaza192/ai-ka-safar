## Top 30 Zaroori Terms

---

**1. AI (Artificial Intelligence):** Computers ko woh kaam karna sikhana jo normal insani intelligence maangta hai.
> 🔹 Jab phone ka keyboard agla word predict kare — yeh AI hai.

**2. LLM (Large Language Model):** Ek giant AI system jo billions of pages par train hua, insani language aur code samajhta aur generate karta hai. Claude, GPT, Gemini — sab LLMs hain.
> 💡 Sochو ek research assistant jisne duniya ki sabse bari library ki har kitaab parhi ho.

**3. Agent (AI Agent):** Ek AI jo sirf sawaalon ke jawab nahi deta. Woh action leta hai, plans banata hai, aur khud kaam karta hai.
> 🔹 Chatbot poochta hai "Dubai ki sasti flight kya hai?" Agent actually airlines search karta hai, prices compare karta hai, aur ticket book karta hai.

**4. Agentic AI:** Woh AI category jo aise agents banane par focused hai jo autonomously plan, reason, aur act karein. 2026 mein AI ka frontier.

**5. Digital FTE (Digital Full-Time Equivalent):** Ek "AI employee" jo full-time human worker ka kaam karta hai — 24/7, fraction cost par.
> 🔹 Customer support Digital FTE roz 500 conversations handle karta hai — 5-10 human agents ka kaam.

**6. Agent Factory:** Is kitaab ka central concept. Spec-driven, human-supervised process jisse AI Workers design, manufacture, aur deploy hote hain.
> 💡 Assembly line ki tarah: har station ek specialized kaam karta hai, parts order mein chalte hain, end mein spec ke mutabiq finished product nikalta hai.

**7. Prompt:** Woh instruction ya sawaal jo tum AI model mein type karte ho.
> 🔹 "Is report ko teen bullet points mein summarize karo" ek prompt hai.

**8. Context Window:** AI ki "working memory" — kitna text woh ek waqt mein parh aur soch sakta hai.
> 💡 Chota context window = choti mez (sirf kuch pages). Bada context window = bari conference table (poora novel ek saath).

**9. Token:** Text ki basic unit jo LLM process karta hai. Roughly ¾ word. "I love biryani" ≈ 4 tokens.
> 🔹 AI APIs use karte waqt tum per token pay karte ho.

**10. Hallucination:** Jab AI confidently kuch aisa generate kare jo sach nahi.
> 🔹 Tum Supreme Court case poochho aur AI fake judgment fake citation numbers ke saath invent kare — confidently, lekin sab jhooth.

**11. Spec (Specification):** Ek detailed blueprint jo exactly describe kare kya banana hai — goals, inputs, outputs, constraints.
> 💡 Architect ka blueprint. Koi builder andaze se shuru nahi karta — woh plan follow karta hai.

**12. Spec-Driven Development (SDD):** Pehle blueprint likho, phir AI se code, tests, aur documentation generate karwao.

**13. Claude Code:** Anthropic ka AI coding agent. Terminal mein baat karo aur woh poora codebase parh ke code likhta hai.

**14. Cowork:** Anthropic ka desktop agent non-coding knowledge tasks ke liye — documents, research, file management.

**15. MCP (Model Context Protocol):** Universal standard jo kisi bhi AI agent ko kisi bhi external tool se connect karne deta hai.
> 💡 USB se pehle har phone ka alag charger tha. MCP AI ka "USB standard" hai.

**16. API (Application Programming Interface):** Rules jo different software programs ko aapas mein baat karne dete hain.
> 💡 Restaurant menu ek API hai. Tum order karte ho (request), kitchen khana banata hai (response).

**17. SDK (Software Development Kit):** Ek platform par applications banane ka pre-built toolkit.

**18. Python:** AI mein sabse popular programming language. Readable, versatile.
> 🔹 `if age > 18: print("Adult")` —거 거 거 거 거 거 거 거 거 거 거 거 거 거 거 거 거 거 거 거 거 거 거 거 거 거 거 거 거 거 거 거 거 거 거 거 거 거 거 거 거 거 거 거 거 거 거 거 거 거 거 거 거 거 거 거 거 거 Python거 English거 거 거 거 거 거 거 거 거 parhta hai.

**19. Git:** System jo har code change record karta hai — kaun, kab, kya. Har version recoverable.

**20. Docker:** Tumhari app ko ek portable box (container) mein package karta hai jo har jagah identically chale.
> 💡 Shipping container — Karachi mein ya samundar mein, andar ka maal ek jaisa hota hai.

**21. Context Engineering:** Woh discipline jo agent ka poora information environment design kare. #1 skill jo ek sellable agent aur ek worthless agent ka farq hai.

**22. Tool Use:** Agent ki ability external tools use karne ki — web search, database query, email bhejne ki.
> 🔹 "Karachi mein mausam" — memory se andaza vs actually weather service check karna.

**23. Guardrails:** Safety constraints jo agent ko woh kaam karne se roktein jo use nahi karna chahiye.
> 🔹 Financial agent ko guardrail: Rs. 5,000,000 se upar koi transaction bina human approval ke nahi.

**24. RAG (Retrieval-Augmented Generation):** AI ko external documents access dena taake woh facts se jawab de, memory se nahi.
> 💡 Open-book exam — AI apni reference material dekh ke answer likhta hai.

**25. 10-80-10 Rule:** AI workforce ka operating rhythm — human direction (10%) → AI execution (80%) → human verification (10%).

**26. AGENTS.md / CLAUDE.md:** Config files jo AI agent ko project ke rules batati hain — coding standards, preferences, architectural decisions.

**27. Orchestration:** Multiple agents ko milke kaam karne ke liye coordinate karna.
> 💡 Cricket team captain — bowling rotations set karna, fielders position karna, strategy adjust karna.

**28. Stateless:** AI ek conversation ke baad sab bhool jaata hai. Har naya chat zero se shuru.
> 💡 Amnesia wala dukaandar — har baar andar aao, woh tumhein stranger samajhta hai.

**29. Deployment:** App ko real users ke liye internet par live banana.

**30. CI/CD:** Automatically code test karna aur deploy karna har change par.
> 🔹 Developer 2 baje code push kare → 3 minute mein tests chalen → sab pass → 2:10 baje live.

## Architecture: Runtime Stack

![10-80-10 Rule](/img/ten-eighty-ten.png)

### Agent Factory
**Process.** Spec-driven, human-supervised method jisse AI Workers design, manufacture, aur deploy hote hain.

### AI-Native Company
**Output.** Running enterprise jo Agent Factory produce karta hai — AI Workers se staffed, management plane se coordinate, humans se directed.

### Two-Layer Model
Humans **Edge Layer** se intent set karte hain. Digital FTEs **AI Workforce Layer** mein execute karte hain.

### Principal
Human jo intent set karta hai, budget define karta hai, authority envelope khenchta hai. Invariant 1.

### Delegate
Personal agent (OpenClaw) jo human ka context rakhta hai, unki taraf se baat karta hai. Invariant 2.

### Paperclip (Manager)
AI-Native Company ka COO — Digital FTEs hire karta hai, kaam assign karta hai, budgets enforce karta hai. Invariant 3.

### Runtime Engine
Execution substrate jo Digital FTE chalti hai. Har FTE apna engine chunti hai.

### Trigger
Bahar ki duniya system ko call karti hai — schedule, webhook, API call. Invariant 6.

| Level | Naam | Bayan |
|-------|------|-------|
