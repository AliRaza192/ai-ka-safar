# Quick Start: Crash Courses

Paanch short primers un readers ke liye jo main kitaab se pehle fast on-ramp chahte hain. Woh chunno jo tumhare halaat se match kare.

## Yeh Kaun Kaam Karta Hai?

Koi bhi jo naye job mein kam background ke saath aaya aur survive kiya, woh pattern jaanta hai. **Pehle**, tumhe kaam ka overview milta hai. **Doosre**, tum woh topics identify karte ho jo actually kaam karne ke liye critical hain. **Teesre**, tum har topic ka woh 80% seekhte ho jo routinely use hota hai, tum kaam shuru karte ho, aur baqi wohi seekhte ho jab zaroorat pare — reference material saath rakhte hue. Is kitaab mein, woh reference kitaab ka har chapter hai — har ek aise likha gaya hai ke padho jab real work mein gap aaye.

Har topic ka har detail pehle se seekhne ki koshish mein mahine lag jaate hain. Tum kuch ship karne se pehle burn out ho jaate. Hamari pedagogy bilkul opposite philosophy pe bani hai: critical 80% cover karo, tumhe kaam pe laga do, aur baqi real use se bharne do. Is section ka har crash course exactly aise design kiya gaya hai.

> **Is kitaab ke baare mein ek note.** Is section ke crash courses tumhe jaldi kaam pe lagate hain. Kitaab ke chapters tumhare post-course reference hain — woh padhne ke liye likhe gaye hain jab real work mein koi gap aaye.

## Thesis Se Shuru Karein

Pehle [thesis](/docs/thesis) parhein. Yeh do versions mein aata hai — ek technical aur business professionals ke liye, aur ek bilkul beginners ke liye — taake har koi background ke bina follow kar sake. Thesis ke baad, [Foundations](#foundations-everyone) aati hain: [Course 1](/docs/ai-prompting-2026) prompting pe aur [Course 2](/docs/how-to-think-ai-era) thinking pe. Har reader yeh leta hai phir mode chunne se pehle.

Tumhe jo mental model chahiye: AI era mein kaam teen layers mein hota hai. Tum **general agents** use karte ho problems solve karne ke liye. Tum **AI Workers** banate ho specialized kaam karne ke liye. Tum un Workers ko **AI-Native Companies** mein assemble karte ho. Har professional engagement ek hi tarah shuru hota hai — ek insaan general agent ko direct kar raha hai. Sawaal sirf yeh hai ke _kaunsa_ agent, jo depend karta hai tum kya karna chahte ho.

> **Ek quick naming note.** Is kitaab mein, **AI Worker**, **Digital FTE**, aur **AI Employee** ek hi idea ko refer karte hain — ek specialized agentic system jo human-defined policy ke neeche real kaam karta hai. Hum _Digital FTE_ use karte hain jab business value pe zor ho, _AI Worker_ jab implementation pe, aur _AI Employee_ jab company ke andar role pe. Kisi aur unfamiliar term ke liye, [glossary](/docs/glossary) tumhara dost hai.

## Apna Mode Chunno

Thesis section [The Two Modes of General Agent Use](/docs/thesis#the-two-modes-of-general-agent-use) do tareeqe describe karta hain jinse log actually general-purpose agents use karte hain. **Mode 1** agar tum AI ko apna kaam karwana chahte ho. **Mode 2** agar tum AI banana chahte jo tumhare liye kaam kare. "Manufacturing" label industrial lagta hai, aur yeh hai — Workers banana unhe use karne se alag discipline hai.

<figure>
<img src="/assets/images/simple-modes-92b3a55599577859267f444ef06fee79.webp" alt="Mode 1 versus Mode 2: Mode 1 mein agent kaam karta hai; Mode 2 mein agent ek Worker banata hai jo kaam karta hai" style={{maxWidth: '600px'}} />
<figcaption>Figure: Mode 1 versus Mode 2 — Mode 1 mein agent kaam karta hai; Mode 2 mein agent ek Worker banata hai jo kaam karta hai.</figcaption>
</figure>

| | **Mode 1 — Problem-Solving** | **Mode 2 — Manufacturing** |
|---|---|---|
| **Yeh chuno agar tum...** | Chahte ho ke AI _tumhe_ kaam tez kare | Chahte ho ke AI Workers banao jo _tumhare liye_ kaam karein |
| **Kiske liye hai** | Koi bhi — engineers ya knowledge workers | Engineers (ya ek knowledge worker ke saath engineer) |
| **Tumhara tool** | Claude Code/OpenCode _ya_ Claude Cowork/OpenWork | Claude Code/OpenCode **banane ke liye**; course pages concepts padhne ke liye teach karte hain pehle, phir agent se banwao |
| **Shuru karo** | Course 3 (engineers) ya Course 4 (knowledge workers) | Course 7 — Build AI Agents |
| **Tum produce karte ho** | Completed kaam | Ek Worker jo kaam karta hai, apne aap |
| **Governed by** | [Seven Principles of Problem Solving](/docs/problem-solving-crash-course) | **[Seven Invariants of the Agent Factory](/docs/thesis#the-seven-invariants-of-the-agent-factory)** |

**Mode 1 ke baare mein ek note.** Agar tum Mode 1 ko aage push karna chahte ho aur ek personal AI assistant deploy karna chahte jo tumhare daily workflows apne aap chalaaye, toh [OpenClaw with General Agents](/docs/openclaw-with-general-agents) (Course 6) follow karo principles course ke baad.

**Mode 2 ke baare mein ek note.** General agent ki output outcome nahi hai — yeh _Worker_ hai jo outcome produce karta hai. Ek developer Claude Code use karta hai spec, build, aur deploy karne ke liye ek code-reviewing Worker. Ek finance analyst, engineer ke saath paired, Claude Code use karta hai spec karne ke liye ek close-process Worker jo har month-end chalta hai. Same tool, same discipline, alag domain.

### Tumhara Starter Path

Agar Mode picker abhi bhi abstract lagta hai, toh yeh same decision fully concrete terms mein hai — woh row chuno jo tumpe fit kare aur sabse pehle wale course se shuru karo. Har path universal Foundations (Courses 1–2) se shuru hota hai.

| Tum ho... | Tumhara starter path | Pehla milestone |
|---|---|---|
| **Bilkul beginner** | Thesis → Course 1 (Prompting) → Course 2 (Thinking) | Foundations laid; neeche mode se continue karo |
| **Knowledge worker** | Foundations (Courses 1–2) → Course 4 (Cowork) → Course 5 (Principles) | AI ke saath real knowledge work ship karo |
| **Engineer** | Foundations (Courses 1–2) → Course 3 (Claude Code) → Course 7 → Course 8 (FTE) | Apna pehla Digital FTE ship karo |
| **Workforce builder** | Engineer path, phir Course 10 (Paperclip) → Course 13 (Evals) → Course 14 (Deploy) | Ek governed AI workforce, cloud pe deployed |

## Courses — Detail Mein

> **Shipped Digital FTE tak ka sabse tez path: Foundations (Courses 1–2) → Course 3 → Course 7 → Course 8 → Course 13 (Reader track).** Taqreeban 12 ghante focused kaam. Baqi courses us Digital FTE ko governed workforce mein badal dete hain — lekin pehla ship karne ke liye tumhein zaroorat nahi.

**Depth ke hisaab se total waqt:** Mode 1 (AI ke saath productive) ~5h · Mode 2 minimum (pehla Digital FTE) ~12h · Mode 2 full (governed workforce) ~25h · Full Agent Factory mastery ~45h (cloud deployment course ke saath).

Dive karne se pehle, do prerequisites jo sab share karte hain: modern [AI prompting](/docs/ai-prompting-2026) aur AI era mein [sochna seekhna](/docs/how-to-think-ai-era). Uske baad, path mode ke hisaab se split hota hai.

### Foundations (Sabke Liye)

1. **[AI Prompting in 2026](/docs/ai-prompting-2026)** — 45-minute, 13-concept primer ChatGPT, Claude, aur Gemini ko 2026 mein achha use karne ke liye: context, reasoning modes, deep research, multimodal, aur AI desktop apps. Woh mechanics jo is kitaab ka har chapter assume karta hai ke tum pehle se jaante ho.

2. **[How to Think in the AI Era](/docs/how-to-think-ai-era)** — _Under development._ Woh cognitive discipline jo AI se real value paane walon ko alag karta hai unse jo nahi paate: kab agent ke paas jaana, kab nahi, aur problems ko aise frame karna ke agent actually madad kar sake.

### General Agents (Apna Co-Worker Chunno)

Yeh woh general-purpose agents hain jo tum har mode mein direct karoge. Engineers coding agent chunte hain; knowledge workers desktop co-working agent. Dono Mode 2 mein bhi reuse hote hain — yeh sirf Mode-1-specific nahi, yeh har mode ke neeche tool layer hain.

3. **[Agentic Coding Crash Course: Claude Code aur OpenCode](/docs/agentic-coding-crash-course)** — 90-minute, 15-concept tour Claude Code aur OpenCode ka. Same vocabulary, thodi alag keybindings; skills dono tools mein cleanly transfer hoti hain. _Engineers ke liye general-agent starting point._

4. **[Cowork Crash Course](/docs/cowork-crash-course)** — 90-minute, 15-concept primer Claude Cowork pe: real desktop knowledge work delegate karna, autonomy ladder, prompt-injection defenses, aur plan-review habit jo zyada tar regrets prevent karta hai. _Knowledge workers ke liye general-agent starting point._

### Mode 1 — Problem-Solving Track

5. **[Problem Solving with General Agents](/docs/problem-solving-crash-course)** — 90-minute, 7-principle crash course woh operating discipline jo kisi bhi general agent — Claude Code, OpenCode, Cowork, ya OpenWork — ko clever toy se aise tool mein badal deti hai jis pe tum real work ship kar sako. Saat principles chaaron tools pe apply hote hain: Bash as the key, code as universal interface, verification as core step, small reversible decomposition, state files mein persist karna, constraints aur safety, aur observability. Chaar-phase workflow shamil hai — explore, plan, implement, commit — aur ek capstone exercise.

6. **[OpenClaw with General Agents](/docs/openclaw-with-general-agents)** — 90-minute, 6-scenario hands-on course jahan tumhara general agent ek Personal AI Employee install aur configure karta hai OpenClaw pe: zero se AI Employee tumhare phone pe, ek custom skill, ek MCP tool, ek heartbeat task, aur closing ACP-spawn demo jahan AI Employee apna khud ka coding agent summon karta hai. Karpathy ka "little skill," expanded. _Prereq: Course 3._

### Mode 2 — Manufacturing Track

Manufacturing path end-to-end saat moves mein chalta hai: Agent banao, usse Employee banao, Employees ko nervous system se connect karo, management add karo, hiring dynamic bao, founder ko free karo, aur saabit karo ke poora workforce measurably trustworthy hai evals ke saath. Is aakhri move ke bina, manufacturing unprovable hai — Workers jo tum measure nahi kar sakte woh Workers hain jo actually ship nahi kar sakte.

7. **[Build AI Agents Crash Course](/docs/build-agents-crash-course)** — 90-minute, 16-concept primer OpenAI Agents SDK pe: agent loop, tools, sessions, streaming, handoffs, guardrails, tracing, day-1 evals, human approval, sandboxed deployment Cloudflare pe, aur DeepSeek V4 Flash cost discipline ke liye. _Prereq: Course 3._

8. **[Agent se Digital FTE Tak](/docs/digital-fte-crash-course)** — 4-hour workshop basic agent ko durable Worker mein badalne ke liye: portable Skills, Neon Postgres with pgvector as system of record, Model Context Protocol unke beech wire ki tarah, audit-trail discipline, approval as authority model, aur ek worked customer-support Worker end-to-end built. 15 concepts, 8 build decisions. Quick Win 15 minute mein; cheat-sheet skim 90 minute mein; full build taqreeban 3 aur ghante. _Prereq: Course 7._

9. **[Digital FTE se Production Worker — Nervous System Ke Saath](/docs/production-worker-crash-course)** — 90-minute, 15-concept course tumhare Digital FTE ko Inngest operational envelope mein wrap karne ke liye: durable execution, event-driven triggers, step memoization, concurrency aur throttling, replay, aur HITL gates. Customer-support Worker extend karta hai taake woh network blips, restarts, aur long-pending approvals survive kare. _Prereq: Course 8._

10. **[Paperclip Se Workforce Banana](/docs/workforce-with-paperclip-crash-course)** — 90-minute, 6-scenario hands-on course jahan tumhara coding agent Paperclip khada karta hai (open-source, MIT-licensed AI-native company control plane), ek keyless local Worker hire karta hai, ek board approval file karta hai permanent audited decision record ki tarah, ek real Gemini-backed Worker swap karta hai taake budget ke paas billable work ho meter karne ke liye, aur poora company history ek SQL query se reconstruct karta hai activity log ke against. Scenarios 1-4 aur 6 bina API key ke chalte hain; sirf budget scenario ko free Gemini key chahiye. _Prereq: Course 8 ya Course 6._

11. **[Fixed se Dynamic Workforce](/docs/dynamic-workforce-crash-course)** — Half-day, 15-concept aur 7-decision workshop jahan Course 10 ka workforce ek capability gap detect karta hai, hire proposal draft karta hai, wohi approval primitive se guzarta hai jo $500 refund gate karta hai, aur ek Legal Specialist provision karta hai Claude Managed Agents pe. Hiring as a callable function. Invariant 6 close karta hai (workforce policy ke neeche expandable hai). _Prereq: Course 10._

12. **[Founder Bottleneck Se Owner Delegate](/docs/identic-ai-crash-course)** — Half-day, 15-concept aur 7-decision workshop jahan workforce ka owner ek Owner Identic AI configure karta hai OpenClaw pe: yeh routine Paperclip approval requests padhta hai, woh clear karta hai jo signed delegated envelope ke andar hain, aur sirf woh decisions surface karta hai jo genuinely human chaahiye. Owner aakhri bottleneck hai — yeh course usse remove karta hai. Invariant 2 close karta hai (har insaan ko delegate chahiye). Downloadable lab starter zip ship karta hai mock endpoints, rules templates, aur sample judgment context ke saath. _Prereq: Course 11._

13. **[AI Employees Ke Liye Eval-Driven Development](/docs/eval-driven-development-crash-course)** — Woh discipline jo manufacturing arc close karti hai aur Courses 3 se 12 ne jo kuch build kiya hai usse wrap karti hai. Chaar learning tracks — Reader (~3-4 ghante, conceptual), Beginner (~1 din), Intermediate (~2 din), Advanced (~3 din full implementation ke liye). 15 concepts plus ek 7-decision lab. Nau-layer evaluation pyramid sikhata hai (unit, integration, output, tool-use, trace, RAG, safety, regression, production) aur chaar-tool stack jo usse bharta hai: OpenAI Agent Evals with trace grading, DeepEval, Ragas, Phoenix. End state: ek workforce jahan har member measurably trustworthy hai, weekly trace-to-regression-test promotion ritual ke saath jo eval suite ko mahine tak alive rakhta hai. _Reader track leaders ke liye; Advanced track shipping teams ke liye. OpenAI Agents SDK ya Claude Managed Agents runtime assume karta hai._

14. **[Apna Agent Harness Cloud Pe Deploy Karo](/docs/deploying-agents-crash-course)** — Woh course jo manufacturing track ne jo kuch build kiya hai woh ship karta hai. Yeh harness/sandbox split sikhata hai: control plane (harness jo secrets rakhta hai, agent loop chalata hai, aur state rakhta hai) alag security boundary mein rehta hai execution plane se (sandbox jahan agent ka generated code actually chalta hai). Tum ek complete production path deploy karte ho: FastAPI on Azure Container Apps harness ke liye, Neon Postgres durable state ke liye, Cloudflare R2 files ke liye, ek code-execution sandbox, chaar-surface observability, aur Course 13 eval suite CI gate ki tarah wired. Chaar learning tracks (Leaders aur architects ke liye Reader; shipping teams ke liye Beginner se Advanced), 17 concepts, aur ek 9-decision agent-driven lab jahan tumhara coding agent ek companion AGENTS.md padhta hai aur harness banata hai jab tum direct karte ho. _Prereq: Course 13 (Decision 8 uski eval suite wire karta hai). Reader track ko cloud accounts ki zaroorat nahi._

15. **[Agentic Architectures Chunna](/docs/choosing-agentic-architectures-crash-course)** — Conceptual crash course pattern selection pe: tumhare task ke baare mein paanch sawaal chaar core patterns mein se ek map karte hain (sequential workflow; single agent + ReAct + tools; planning + ReAct execution; multi-agent specialist), plus reflection as additive layer upar. Discipline architectural fit se choose karna hai, jo impressive lagta hai usse nahi: har pattern task pe ek bet hai, aur sahi woh hai jiski assumptions reality se match karte hain. Paanch-sawaal decision tree sikhata hai, do equally common failure modes (overshooting aur undershooting), runtime signals jo mismatch reveal karte hain, aur kaise har pattern tumhari deployment topology aur eval suite ke saath compose hota hai. Chaar learning tracks (Reader ~2-3 ghante conceptual; Beginner ~1 din; Intermediate ~2-3 din; Advanced ~4-5 din), paanch-case decision lab, aur ek printable classify-this-task worksheet design reviews ke liye. _Prereq: tum already agents build aur evaluate kar sakte ho; cross-references agent-building, operational-envelope, aur eval courses._

16. **[Payment-Enabled Agents: ACP, AP2, x402, aur MPP](/docs/payment-enabled-agents-crash-course)** — Multi-track crash course chaar protocols pe jo agents ko paisa move karne dete hain: ACP consumer shopping ke liye, AP2 authorization mandates ke liye, x402 HTTP-native machine payments ke liye, aur MPP session-based settlement ke liye. Key idea: chaar layers hain, rivals nahi. Tum ek use case padhte ho, har layer ke liye ek protocol chunte ho (discovery, authorization, commerce, settlement), aur unhe OpenAI Agents SDK code ki tarah compose karte ho, tool-input guardrail ke saath jo payment hone se pehle rok deta hai. Chaar learning tracks (Reader ~2-3 ghante conceptual; Beginner se Advanced shipping teams ke liye), 19 concepts, paanch-decision lab, aur teen-level spend-limit discipline jo runaway agent ko wallet drain karne se rokti hai. _Prereq: Course 7 (OpenAI Agents SDK); Course 9 (Inngest) aur Course 14 (cloud deployment) ke saath pair hota hai._

## Khatam Hone Pe Tumhare Paas Kya Hoga

Jab tum is section ke end tak pahunchoge, toh tum sirf Agent Factory thesis nahi samjhoge — tum uske against build kar chuke hoge. Tumne general agents use kiye honge real work ship karne ke liye. Tumne kam se kam ek Digital FTE deploy kiya hoga jo tumhare bina chalta hai. Tumne usse nervous system se connect kiya hoga, Paperclip-governed workforce ke andar rakha hoga, us workforce ko apne khud ke colleagues hire karte dekha hoga, aur khud ko us bottleneck se free kiya hoga Identic AI ke through. Tumne poora cheez apne khud ke likhe hue evals mein wrap kiya hoga, taake tum saabit kar sako — umeed nahi — ke har Worker trustworthy hai.

Yeh difference hai is kitaab aur baqi har AI course mein: tum notes ke saath finish nahi karte. Tum ek working AI workforce ke saath finish karte ho.

Aur kitaab useful rehti — chapters woh reference hain jise tum har baar reach karte ho jab atak jaate ho.

Is section ke baad sab kuch tumne jo pehle build kiya hai usse refine karta hai. Ab apna mode chuno aur shuru karo.
