# Panaversity Certified Developer: Foundations

**PCDV-F tumhe Anthropic ki CCDV-F (Claude Certified Developer – Foundations) exam ki tayyari karne ke liye design kiya gaya hai.** Ye same published blueprint follow karta hai, same objectives ko same weights pe cover karta hai, lekin wahin nahi rukta.

PCDV-F us blueprint ko ek level up le jaata hai concepts ko broader, vendor-neutral context mein test karke, related topics add karke jo real-world AI work mein important hain, aur wo gaps bharta hai jo official exam ke scope se bahar hain.

PCDV-F pass karne se tumhe strong, low-cost signal milta hai ke tum official Anthropic certification attempt karne ke liye tayyar ho, aur saath hi practical AI engineering ke liye mukammal foundation bhi ban raha hai.

[Official CCDV-F exam guide parhein](/docs/certifications#official-exam-guides).

| Exam | Items | Duration | Cut score | Fee |
|---|---|---|---|---|
| **PCDV-F** (Panaversity) | 53 items | 120 minutes | 720 / 1,000 | Students: do free attempts, phir fee |
| **CCDV-F** (Anthropic) | 53 items | 120 minutes | 720 / 1,000 | $125 per attempt |

[Pehle se jaante ho kya chahiye? Schedule karo↓](#apna-exam-schedule-karo)

Ye us insaan ka exam hai jo ship karta hai. Tum API call karte ho, tool wire karte ho, tum model ki ghalati handle karte ho jo teen bajay subah hui, aur result baad mein tumhari zimmedari hai.

PCDV-F us kaam ko examine karta hai. Ye Panaversity ka developer credential hai, Anthropic ke **Claude Certified Developer – Foundations** blueprint ke saath aligned, aur ye poochta hai ke tum ek aisa LLM application design, integrate, aur operate kar sakte ho jo production mein zinda rahe, demo mein nahi.

**Ghareeb ke liye ye kya prove karta hai wo AI fluency se tang aur mushkil hai. Ye prove karta hai ke tum build aur ship kar sakte ho, sirf design nahi.** Isi liye ye FDE path ke andar nahi balki bagal mein hai: architecture judgment batata hai kya banana chahiye, aur ye credential batata hai ke cheez ban gayi.

### Ye Kis Ke Liye Hai, Aur Kis Ke Liye Nahi

Anthropic ki guide twin ke audience ka naam seedha deti hai: technical professionals jo production-grade AI solutions build, integrate, aur ship karte hain large language models ka use karke, khaas taur pe AI aur machine learning engineers, technical leads, aur senior software engineers jo business requirements aur implementation ke beech kaam karte hain.

Phir wo batati hai ke ye **kiske liye nahi** hai, aur list book karne se pehle parhne layak hai. Non-technical ya casual users jo Claude-based applications use karte hain. Koi bhi jiske paas hands-on software development experience na ho. Roles jo sirf prompt writing tak limited hon bina wider application development responsibility ke.

Agar tum aaj us doosri list mein ho, [PCAO-F](/docs/certifications/pcao-f) wo exam hai jo tumhare liye fit hai, aur ye waise bhi FDE path pe pehla step hai.

## Same Blueprint, Ek Level Upar

**PCDV-F usi blueprint ko ek level up le jaata hai.** Ye Anthropic ke published Developer Foundations blueprint pe har objective examine karta hai, published weights pe; CCDV-F ka practice run nahi, aur na hi uska imitation. Phir chalta rehta hai, kyunki courses bhi chalte hain: wohi judgment vendors ke across poochha jaata hai, OpenAI Agents SDK aur open-weights models ko study guide mein Claude courses ke bagal mein rakhte hue.

| Panaversity exam | Code | Anthropic twin | Code | Cut score |
|---|---|---|---|---|
| Panaversity Certified Developer: Foundations | **PCDV-F** | Claude Certified Developer – Foundations | **CCDV-F** | 720 out of 1,000, dono |

Twin **53-item, 120-minute, $125 proctored exam** hai. Ye implementation judgment examine karta hai aik vendor ke product surface ke andar: Messages API, Claude Agent SDK, `CLAUDE.md`, `settings.json`, Claude Code.

Panaversity sitting ye sab poochta hai aur phir har sawaal ka professional version poochta hai. API contract, aik vendor ke Messages API ki jagah. Agent loop, aik framework ke harness ki jagah. Evaluation discipline, aik product ke debugging view ki jagah. Secrets aur identity obligation, aik platform ke settings file ki jagah.

**Yehi fark poora wajah hai ke exam aage jaata hai.** Tum aise customer ke saamne khade hoge jo Claude chalaye, ya apne hardware pe open-weights model chalaye, ya migration ke chhe mahine mein ho. Tumhe dono mein sahi hona padega. Exam jo sirf aik vendor ka surface test kare ye nahi bata sakta ke tum sahi ho ya nahi.

**CCDV-F wo credential hai jo travel karta hai.** Ye Anthropic ki hai, employer verify kar sakta hai, aur wohi tumhare CV pe hona chahiye. PCDV-F uska rival nahi hai aur use replace nahi karta. Ye wohi blueprint cover karta hai pehle ke tum asli exam do, aur portable half add karta hai.

Panaversity apne exams administer aur proctored karta hai, unhe usi 720 out of 1,000 standard pe rakhta hai jo Anthropic use karta hai, aur chaar chalata hai, har aik aik Anthropic credential ke saaligned. Ye developer wala hai.

## Ye Kya Test Karta Hai

**Aath published domains hain.** Ye unke weights hain, official exam guide se.

| Domain | Weight |
|---|---|
| **Applications and Integration** | **33.1%** |
| **Model Selection and Optimization** | **16.8%** |
| Agents and Workflows | 14.7% |
| Prompt and Context Engineering | 11.0% |
| Tools and MCPs | 10.6% |
| Security and Safety | 8.1% |
| Claude Code | 3.1% |
| Eval, Testing, and Debugging | 2.6%**

**Weights is page ki sabse useful cheez hain, kyunki wo itne uneven hain.** Applications and Integration akele exam ka tisra hissa hai, agle domain se do se zyada. Model Selection and Optimization add karo aur tum aadhe se zyada pe pahunch jaate ho agents, tools, ya security se pehle.

Sabse bade domain ke andar dekho aur picture aur sharp hoti hai. Guide ise chhe objectives mein tootta hai aur har ek ka weight publish karta hai.

| Objective (Applications and Integration ke andar) | Weight |
|---|---|
| Claude Application Design | 8.6% |
| Software Engineering Foundations | 7.4% |
| Claude API Mechanics | 6.8% |
| Configuration Management | 4.1% |
| Understanding Requirements | 3.4% |
| Systems Life Cycle | 2.8% |

Upar ke teen rows exam ke kahin bhi teen sabse bade single objectives hain, har doosre domain ke har objective se aage. **Ye software engineering exam hai jismein LLM hai, LLM exam nahi jismein kuch code attached hai.** REST APIs, JSON, asynchronous programming, version control, code review, aur refactoring apne terms pe examine hote hain, Claude ke instructions across interfaces ko kaise interpret karta hai aur `CLAUDE.md`, `settings.json`, model pinning, aur prompt versioning kaise manage hote hain uske bagal mein.

Doosra surprise neeche hai. Claude Code aur Eval, Testing, aur Debugging milke 6 percent se kam hain, jo kisi bhi topic ke normal conversation mein weight se kaam hai. Dono padho. Kisi ko bhi table ke top ka time mat do.

Panaversity sitting wo aath domains aur unke weights rakhti hai, phir wo coverage add karti hai jo developer ko aise customer ke saamne chahiye jo kuch standardize nahi kar rakha: portable API aur SDK patterns providers ke across, evaluation aur regression discipline jo aik product ke tooling se tied nahi, cost aur latency reasoning jab endpoint ke peeche wala model swap ho sakta hai, aur security aur identity obligations jo tum kisi bhi host ke saath leke chalte ho.

Matching Panaversity course mein enrolled students ke liye do attempts free hain. Teesra ya baqi attempts pe fee lagti hai, aur jo enrolled nahi hai wo proctoring ke liye pay karta hai. Dono fees abhi announce nahi hui.

## Pass Karne Ke Baad

Clear ho ke ye credential kya khulta hai aur kya nahi.

**PCDV-F FDE gate ka part nahi hai.** Gate hai PCAO-F pehle, phir PCAR-F. Dono pass karna candidate ko Panaversity FDE Internship Program ke liye qualify karta hai, jahan Anthropic exams ki registration assistance milti hai. Sirf PCDV-F pass karna kaafi nahi.

**Jo ye karta hai wo build prove karta hai.** [Vertical FDE](/docs/roles-this-book-trains) ke liye ye wo credential hai jo us sawaal ka jawab deta hai jo architecture credential chhod jata hai: ke jo insaan ne system design kiya wo use khada bhi kar sakta hai, integrate bhi, instrument bhi, aur chalata bhi rakh sakta hai. Senior software engineer ke liye jo agentic kaam ki taraf move kar raha hai, ye sabse clean independent statement hai ke move actually ho chuka hai.

Aik structural detail order choose karne se pehle jaanne layak hai. Anthropic ki taraf, **CCDV-F Claude Partner Network tier eligibility mein count hota hai**, Architect Foundations aur Architect Professional ke saath. Associate credential nahi karta. Agar tumhare employer ka partner standing matter karta hai, developer exam optional extra nahi hai.

FDE path pe ho toh PCAO-F aur PCAR-F ke baad lo, ya pehle lo agar tumhara kaam building hai aur proof chahiye jo usse match kare.

### Cut score percentage nahi hai

**720 scaled score hai 100 se 1,000 range pe**, standard-setting study se set kiya gaya. Ye 72 percent correct nahi hai, aur guide kabhi percent-correct passing threshold publish nahi karta. Tumhare score report pe domain-wise percentages informational hain aur pass ya fail decide karne ke liye use nahi hote.

**Recertification.** Credential 12 months valid hai. Time pe renew karne ke liye review karo ke certify hone se pehle kya badla hai aur Anthropic Partner Academy pe free, non-proctored assessment complete karo. Time pe renewal pe koi fee nahi. Lap ho jaye toh full exam full fee pe dobara lo. Agar exam content significantly badalta hai, Anthropic renewal assessment ki jagah full retake mang sakta hai.

**Failed attempt ka kitna lagta hai.** Fee har attempt pe lagti hai. Pehle failure ke baad 14 din wait, doosre ke baad 30 din, teesre ke baad 90 din, aur rolling twelve months mein same exam pe chaar attempts tak. Appointment se 24 ghante pehle tak free cancel ya reschedule kar sakte ho; us window ke andar, aur no-show ya late arrival pe, fee forfeit ho jaati hai. Exam shuru hone se pehle confidentiality agreement accept karna hota hai, aur decline karna session refund ke saath khatam karta hai. Appeals 14 din ke andar Pearson VUE ke paas jaati hain, aur na hi standard-setting outcome appealable hai aur na hi individual item content. **Yehi arithmetic hai jo free Panaversity attempt tumhe bachane ke liye hai.**

**Prerequisites.** Koi nahi. Guide seedha kehti hai ke koi course ya prior certification zaroori nahi, aur recommended experience — lagbhag ek se paach saal software engineering, chhe mahine ya zyada hands-on Claude ya comparable LLM systems ke saath, Python ya TypeScript, aur REST APIs aur CLI tools ke saath fluency — recommended hai, required nahi. Ye bhi kehti hai ke koi single required course nahi hai aur koi resource passing result guarantee nahi karta, aur ye isi kitaab pe bhi utna lagu hota hai jitna kisi aur pe.
